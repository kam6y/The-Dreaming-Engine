# BACKLOG — 縦切り完成後の拡張アイデア

/loop での拡張フェーズはこのリストから選ぶ。上の項目ほど優先度が高い。
1項目が大きい場合は分割してROADMAP末尾に「M7+」として展開してからやる
(その場合、本ファイルのチェックは展開時ではなく対応するM7+の完了時に付ける)。
完了した項目はチェックを付ける。**Claude Codeによる新規アイデアの追記は
「優先度: 低」の末尾のみ**とする。項目の優先度変更・並び替え・削除、および
「高」「中」への追加は人間だけが行う(人間の優先順位コントロールと
ループ終了条件を保つため)。
拡張時も `docs/spec/` の仕様と `CLAUDE.md` の品質ゲートに従うこと。
