# BACKLOG — 縦切り完成後の拡張アイデア

/loop での拡張フェーズはこのリストから選ぶ。上の項目ほど優先度が高い。
1項目が大きい場合は分割してROADMAP末尾に「M7+」として展開してからやる。
完了した項目はチェックを付け、新しいアイデアは適切な優先度の位置に追記する。
拡張時も `docs/spec/` の仕様と `AGENTS.md` の品質ゲートに従うこと。

## 優先度: 高(ゲーム体験の底上げ)

- [ ] タイルマップのグラフィック改善(Kenney等CC0素材への置換、またはオートタイル実装)
- [ ] 装備システム(武器・防具のスロット、攻防への反映、店での売買)
- [ ] スキル拡充(主人公のスキルツリーまたはレベル習得スキル5種以上)
- [ ] 敵バリエーション追加(雑魚+3種、中ボス1種。Image Genでグラフィックも生成)
- [ ] NPCの記憶の永続化強化(セーブを跨いだ会話要約の保存と、好感度による態度変化の拡充)
- [ ] 効果音・BGMの整備(オープンライセンス素材の選定・組み込み)

## 優先度: 中(世界の拡張)

- [ ] 第2エリア(新しい街または集落+フィールド+ダンジョン。Image Genで背景・NPC立ち絵生成)
- [ ] メインクエスト第2章(夢の機関の謎を深掘りする筋。骨子を`game-design.md`に追記してから実装)
- [ ] サブクエストのテンプレート拡充(`propose_quest`に護衛型・調査型を追加。防御仕様の検証も拡張)
- [ ] 夢シーンの演出強化(`trigger_world_event`の型追加: 市場の変化、失踪、夢の侵食度など)
- [ ] 状態異常・属性の拡充(毒・暗闇・恐怖など+耐性)
- [ ] ミニマップまたは全体マップUI

## 優先度: 低(磨き込み)

- [ ] 昼夜サイクルと時間帯によるNPC配置変化
- [ ] 実績システム(夢の欠片収集)
- [ ] 難易度設定
- [ ] ゲームパッド対応
- [ ] AI応答のキャッシュ・プリフェッチによる体感レイテンシ改善
- [ ] セーブスロット複数化
