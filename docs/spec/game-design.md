# ゲーム仕様 — The Dreaming Engine

## コンセプト

- ジャンル: 日本語のダークファンタジー2D RPG(見下ろし型・ターン制戦闘)
- 世界観の骨子: 世界は「夢見る機関(The Dreaming Engine)」が紡ぐ夢でできている。
  機関は壊れかけており、夢は綻び、悪夢が滲み出している。プレイヤーは記憶を失った
  旅人として、まどろみの街に流れ着くところから始まる
- トーン: 暗く、物哀しく、しかしどこか優しい。過度なゴア・グロテスク表現はしない
- 生成AIは「夢を紡ぐ機関の声」としてゲームに溶け込む。NPCの言葉の揺らぎや
  世界の変化は「夢だから」という世界観的必然を持つ
- 固有名詞(街・NPC・敵・アイテムの名前)とロアの細部は、このトーンに合う範囲で
  実装者(codex)が創作してよい。決めた内容はJOURNALに記録し、一貫して使うこと

## 画面・シーンフロー

```
タイトル画面 ──新規ゲーム──▶ オープニング(静止画+テキスト) ──▶ 街
     │                                                        │
     └──つづきから──▶ セーブ地点(街の宿屋)                 探索(フィールド/ダンジョン)
                                                              │
                                                    エンカウント ──▶ 戦闘シーン ──▶ 探索に戻る
                                                              │
                                                    ボス撃破 ──▶ エンディング ──▶ タイトル
```

- 解像度: 論理960x540(16:9)を基準にブラウザウィンドウへスケール
- Escでメニュー(所持品・ステータス・クエストジャーナル・設定・タイトルへ戻る)

## マップ構成(縦切り)

| マップ | 内容 |
|---|---|
| 街(拠点) | NPC4人、宿屋(セーブ/宿泊)、店、酒場、教会。安全地帯(エンカウントなし) |
| フィールド | 街とダンジョンをつなぐ荒野。敵シンボル2-3体、採取ポイント1-2箇所 |
| ダンジョン1層-3層 | 悪夢の裂け目。層が深いほど敵が強い。3層最深部にボス「夢喰い」 |

- グリッドベース(タイル32px)。移動はグリッド単位のスムーズ補間(4方向)
- マップデータはJSON(タイル配置・衝突・イベント配置・遷移ポイント)で管理し、
  zodスキーマを`shared`に定義する

## NPC(4人)

| 役割 | 機能 | AI会話 |
|---|---|---|
| 宿屋の主人 | 宿泊(HP/MP全回復+夢シーン+セーブ) | あり。街の日常と噂を知る |
| 商人 | 店(購入・売却) | あり。商品や旅の話題 |
| 情報屋(酒場) | サブクエスト受注・報告の窓口 | あり。`propose_quest`の起点 |
| 謎の司祭(教会) | メインクエスト進行役 | あり。世界の真実に近い存在 |

- 全NPCが好感度(0-100、初期30)と会話記憶(要約)を持つ。詳細は`ai-integration.md`
- 好感度による変化(縦切り時点): 50以上でAIが`give_item`を提案できる。
  口調・態度の変化はプロンプトに好感度を渡すことで自然に表現する
- メインクエストの進行に必須の会話は**選択肢**で進む(AI生成に依存しない)。
  自由入力の雑談はその周辺を彩る位置づけ

## メインクエスト(AI非依存で完結すること)

1. オープニング: 記憶を失った旅人が街に流れ着く
2. 司祭との会話(選択肢)で「夢の綻びの原因はダンジョン最深部の『夢喰い』」と知る
3. ダンジョン攻略(1層→3層。層ごとの小さな仕掛け: 鍵、スイッチ程度で可)
4. ボス「夢喰い」撃破
5. エンディング(静止画+テキスト)

- サブクエスト(AI生成)は情報屋経由で受注する任意コンテンツ。詳細は`ai-integration.md`

## ターン制戦闘

- パーティは主人公1人(縦切りでは単独。拡張で仲間を検討)
- コマンド: たたかう / スキル / どうぐ / にげる
- 行動順: 素早さ降順(同値は乱数)
- ダメージ式(初期値。バランス調整可、ただし式の構造とテストは維持):
  `max(1, floor(攻撃力 × rand(0.9..1.1)) - floor(防御力 / 2))`
- スキルはMP消費。縦切りでは主人公に攻撃スキル1種+回復スキル1種で可
- 状態異常: 最低1種(例: 毒=毎ターン最大HPの5%ダメージ)
- にげる: 成功率 = 50% + (自素早さ - 敵素早さ) × 2%(10%-90%にクランプ)。ボス戦は不可
- 全滅時: 所持ゴールド半減で街の宿屋で目覚める(「悪夢から覚めた」演出)
- 敵AI(行動選択)は決定論的なルール(HP閾値・ローテーション)。生成AIは使わない
- 生成AIの関与は演出のみ: 戦闘勝利後の戦果描写、ボス戦の要所の台詞(`narrate`)。
  これらが取得できなくても定型文で進行する

### 敵(縦切り分。名前・見た目はcodexが創作)

| 区分 | 想定 |
|---|---|
| 雑魚3種 | フィールド1種、ダンジョン浅層1種、深層1種。行動2パターン程度 |
| ボス「夢喰い」 | HP多め+2形態(HP50%以下で行動パターン変化)。推奨レベル5-6 |

## 成長・経済

- レベル1-10想定(縦切り)。経験値テーブル・能力成長は実装者が初期値を決め、
  「Lv1で最弱雑魚に3-5ターンで勝てる」「推奨Lv未満でのボス挑戦は高確率で全滅」を
  ユニットテスト(シミュレーション)で担保する
- 通貨: ゴールド。入手は戦闘・サブクエスト報酬。用途は店(消耗品)と宿泊費(少額)
- アイテム(縦切り): 回復薬(小/中)、解毒薬、松明(ダンジョンの暗がり演出用)、
  クエスト用アイテム数種。`shared`のアイテム定義に一元管理

## セーブ/ロード

- 宿屋でのみセーブ(スロット1)。サーバーが`saves/save1.json`に保存
- 保存内容: プレイヤー状態・位置・インベントリ・クエスト進行・NPC好感度・
  会話要約・世界状態(天候等)・プレイ時間
- zodスキーマでバージョン付き管理(`version`フィールド)。ロード時に検証し、
  壊れたセーブはエラー表示して新規開始を促す(クラッシュさせない)

## 操作

| 入力 | 動作 |
|---|---|
| WASD / 矢印 | 移動 |
| スペース / Enter | 調べる・話す・決定 |
| Esc | メニュー / キャンセル |
| 会話中 | 選択肢はカーソル+決定、自由入力はテキストボックス(送信=Enter) |

## 完成(縦切り)の定義

タイトル→新規→メインクエスト→エンディング→タイトルまで人間が通しプレイでき、
`pnpm check`と全E2Eが緑で、主要シーンの画像アセットが組み込まれていること。
