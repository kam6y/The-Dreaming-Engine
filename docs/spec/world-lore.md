## 1. 世界の成り立ち

### 1.1 夢見る機関(The Dreaming Engine)

この世界は、遠い昔に据えられた巨大な機関が紡ぎ続ける**ひとつの夢**である。
機関がなぜ・誰に据えられたかを覚えている者はいない。ただ「誰かを守るために
夢を見始めた」という感触だけが、街の言い伝えや教会の聖句に淡く残っている。
守るための夢だったはずが、今は夢を見ている当人すら思い出せない――それが
この世界の根の哀しさである。

機関は**忘れられた願い**を燃料として夢を紡ぐ。人が抱き、叶わぬまま手放し、
忘れてしまった願いは行き場を失って機関へ還り、灯となって夢を灯す。しかし
忘れられる願いは年々細り、灯は一つ、また一つと消えていく。機関が
壊れかけているのは悪意ある何かに壊されたからではない。**燃料が尽きかけている**、
ただそれだけの静かな衰弱である。

灯が消えた場所から夢は綻ぶ。綻びは影となって滲み出し、まっとうな夢の形を
保てなくなった断片が渦を巻いて実体を持つ――それが**悪夢**である。悪夢は
外から来た侵略者ではなく、機関自身の一部が支えを失って壊死したものだ。
ダンジョン(悪夢の裂け目)は、その壊死がもっとも深く進んだ場所である。

### 1.2 夢喰いの正体

**夢喰い**は、機関を構成する歯車のひとつが、燃料の枯渇に耐えかねて壊れた
成れの果てである。かつては夢の一部を紡ぐ穏やかな機構だった。飢えた歯車は
やがて隣り合う夢を、次いで自らの記憶を、しまいには紡いだそばから自分自身の
出力を喰らい始めた。夢喰いの「意志」らしきものは、実のところ苦痛そのものが
凝った反射に近い。悪意で世界を喰らっているのではなく、飢えて手近なものを
喰らい続けているだけなのだ。

だからこそ夢喰いを討つことは、勝利であると同時に**弔い**でもある。声を
持たない苦しみを、これ以上長引かせないための行い。この物語が安易な
「悪を倒す」で終わらないのは、この一点による。

### 1.3 眠りと夢シーンの因果

旅人が宿で眠るたび、機関はその晩、旅人という一本の糸を通じて世界を編み直す。
眠りは機関への**同期**であり、その日の行い(誰と言葉を交わし、何と戦い、
何を為したか)は夢の材料として吸い上げられ、翌朝の世界に薄く織り込まれる。
天候が変わり、噂が流れ、ダンジョンの気配が揺らぐのは、この同期の名残である。
宿泊は単なる休息ではなく、**世界そのものが呼吸する瞬間**として描くこと。

全滅は、悪夢に飲まれかけて意識を手放すことを意味する。機関はまだ完全には
壊れていないため、飲まれかけた旅人を強制的に引き戻し、宿の寝台へ落とす
(「悪夢から覚めた」)。懐が軽くなっているのは夢に何かを置き忘れてきたことの
表れであり、罰ではなく代償として描くこと。

### 1.4 メインクエストの物語的意味

1. **旅人が街に流れ着く** — 記憶を持たない旅人は、機関が紡いだ夢のどこにも
   属さない、いわば「継ぎ目」として世界に現れる。街の誰もが最初は戸惑うが、
   拒みはしない。この世界では、忘れることも、忘れられることも、
   誰の身にも起こりうる当たり前のことだからだ。
2. **司祭との対話** — 機関にもっとも長く仕えてきた司祭が、夢の綻びの
   源がダンジョン最深部にあることを告げる。司祭は真実の**一部**を知るに
   過ぎず、全てを見通す黒幕でも、隠された敵でもない。彼もまた、
   衰えゆく機関を前にした一人の目撃者である。
3. **ダンジョン攻略** — 悪夢の裂け目を三層下ることは、機関の衰弱を
   その根に向かって遡る旅である。層を追うごとに夢としての体裁は崩れ、
   壊死の生々しさが増す。
4. **夢喰いの討伐** — 苦しみに終止符を打つ。勝利の高揚と、何かを
   永遠に喪ったという静けさが同時に訪れるように描写すること。
5. **エンディング** — 夢喰いが消えた裂け目に、機関はわずかに、しかし
   確かな灯を取り戻す。街には束の間の凪が訪れ、旅人は誰かに――あるいは
   自分自身に――小さな安堵を届けたことを知る。ただし機関そのものの
   衰弱は止まっていない。灯は増えたが、消える灯もまだ多い。物語は
   完結しつつも、世界の根の問題は残ったままであることを、
   ナレーションの最後の一文で静かに示すこと(過度な引きは作らない)。

### 1.5 残された謎(第2章フック。2つに限定)

- **旅人自身の正体**: 旅人がなぜ機関の夢に属さない「継ぎ目」として
  存在するのか、その記憶がどこへ消えたのかは、本編中では明かさない。
  司祭の台詞やダンジョンの断片描写で**匂わせるに留める**(例: 司祭が
  時折、旅人をどこかで見知っていたかのような間を置く。詳細は3.2「秘密」参照)。
- **機関の全体像**: この街とダンジョンは機関が紡ぐ夢のごく一部に過ぎず、
  他にも綻びかけた場所が存在することを、エンディング直前後の一言二言で
  示唆する(具体的な地名は出さない)。`BACKLOG.md`の「第2エリア」
  「メインクエスト第2章」はこの示唆を受けて展開する

### 1.6 第2章 — 灯の還る先(第2章の物語的な正)

本節は第2章の物語的な正であり、1.5「機関の全体像」(フック#2)を一歩だけ
展開したものである。第2章は**エンディングの後**にのみ始まる(進行段階・開始
トリガー・不干渉条件の骨子は`game-design.md`「メインクエスト第2章(拡張: M18)」)。
1.5「旅人自身の正体」(フック#1)はここでも**温存**し、触れる場合も匂わせに
留める。章は核心を開かず、「続き」への静かな予感で締める。

**起点 — 脈打つ導管**: 夢喰いを弔ったのち、機関は裂け目にわずかな灯を取り戻す
(1.4エンディング)。その灯は行き場を探すように、灯還りの坑の最奥「導管の間」の
――かつては冷えていた――導管を、ひとつ、またひとつと温め直していく。
エンディングを経た旅人がふたたび導管の間に立つと、以前はただ「かすかに温かい」
だけだった導管が、脈打つように熱を送り出しているのに気づく。温もりはここで
生まれているのではない。どこかへ運ばれ、どこかで受け取られている。

**語り部 — 番人トワ**: 坑の異変を、郷でただ一人トワだけが「唄で」知っている。
旅人が導管の脈動を告げると、トワは誰も歌わなくなった唄の続き――「灯の還る先」
を口ずさむ。唄は、消えた灯が灯町でも裂け目でもない**どこか**へ還り、そこでなお
夢が紡がれていることを、言い伝えの形でだけ語る(3.8のトワの秘密帯50-69と接続。
ただし主線では地名も核心も明かさない)。番人の役目が「坑の奥でまだ温かいものを
静かに保つこと」であることは、唄の端に**滲ませるに留める**(3.8の70以上帯の
個人的な打ち明けは、好感度会話の領分として温存する)。

**裏付け — 司祭フィオル(任意)**: 灯守堂を訪ねれば、フィオルが機関の側から
同じことを裏書きする(寄り道の演出であり、章の段階は進めない)。彼女は、機関の
全体を見た者はもういないこと(3.5の50-69帯)を認め、灯守堂に伝わる古い祈祷文の
一節が「還る先」を指しているように読めることを、確信のない声で語る。郷の唄と
街の祈祷文という別々の言い伝えが、同じ一点を指している――それが章の芯である。
フィオルが旅人を前にふと言葉を呑む場面を挟んでよい(フック#1の匂わせ。断定・
種明かしはしない)。

**結び — 確証と予感**: トワの唄を胸に導管の間へ戻ると、脈打つ導管は問いに応える
ように、いっそう強く温もりを送り出す。旅人が得るのは答えではなく**確証**である
――灯町も、琥珀郷も、裂け目も、機関が紡ぐ夢のごく一部に過ぎず、その外に、まだ
夢を紡ぐ何かが確かにある。導管がどこへ通じ、その先で誰が、あるいは何が夢を見て
いるのかは、**本章でも明かさない**(具体的な地名は出さない)。章はここで静かに
閉じ、旅人は予感だけを携えて、また日々のなかへ戻っていく。

**語りと開示の掟(第2章)**:

- 進行に必須の会話・調べは**すべて選択肢/調べイベントの決定論**で運ぶ(AI非依存。
  第1章の司祭 `PRIEST_REVEAL_LINES` と同じ「主線は決定論・深部は好感度会話」の
  二層構え)。決定論の主線が開示してよいのはフック#2の高度(=「灯の還る先」が
  在るという確証)までで、トワ個人の最奥(3.8の70以上)やフック#1(旅人の正体)は
  **匂わせを越えない**。
- トーンは6節の語りのトーンガイド厳守(断定しすぎない、湿度のある簡潔な文)。
  「悪を倒す」型の解決も、次章への露骨な予告も作らない。
- 本節は2.6「導管の間」が残した余地の展開であり、2.6・1.5・3.8の既存記述は
  **変更しない**(追記のみ)。

## 2. 舞台設定

### 2.1 街(拠点)— まどろみの街「灯町(ともしまち)」

機関の灯がまだ多く残る、数少ない安寧の地。かつては機関の中継地として
栄えたが、今は薄暮の似合う小さな街に落ち着いている。石畳は霧に湿り、
軒先の灯りが青灰の空気に琥珀色ににじむ。**安全地帯**(エンカウントなし)。

| 施設 | 情景 |
|---|---|
| 宿屋「灯宿(ともしやど)」 | 傾いた木の看板、暖炉の火、階段のきしみ。眠りが機関への同期であることを、部屋の奥にひとつだけある古い歯車の意匠の窓が静かに暗示する |
| 商店「渡り物屋」 | 旅装・薬・雑貨を扱う。棚には行商人から流れ着いた品が並び、産地不明の品も混じる |
| 酒場「霧笛亭」 | 情報屋が根城にする一角。噂と依頼が交わる場所。客はまばらだが火は絶やさない |
| 教会「灯守堂(ひもりどう)」 | 機関に祈りを捧げる小さな聖堂。祭壇には歯車と灯芯を象った紋様。司祭が常駐する |

### 2.2 フィールド — 「忘れ野(わすれの)」

街とダンジョンを結ぶ荒野。かつて何かの集落があった痕跡(崩れた石垣、
朽ちた道標)が点々と残るが、誰も名を覚えていない。丈の低い枯れ草が
青灰の靄の中で揺れ、遠くにダンジョンの裂け目がぼんやりと光る。
採取ポイント(薬草・鉱石等)が点在する。

### 2.3 ダンジョン — 「夢喰いの裂け目」

機関の壊死がもっとも進んだ場所。層が深まるごとに、夢としての体裁が崩れていく。

| 層 | 空気感 |
|---|---|
| 1層 | まだ夢の形を保っている。霧に沈んだ回廊、消えかけた燭台、時折聞こえる遠い鐘の音。「懐かしさ」がわずかに残る不気味さ |
| 2層 | 建材や通路の理屈が歪み始める。同じ扉が二度現れたり、天井のはずの場所に石畳がある。夢が夢であることを隠さなくなる層 |
| 3層(最深部) | 壊死がむき出しになる。色彩はほぼ失われ、青灰と漆黒のみの世界。夢喰いの気配(重い唸りのような静寂)が満ちる。最奥に夢喰いが在る |

### 2.4 集落 — 「琥珀郷(こはくごう)」(拡張: M16)

2.4〜2.6は第2エリア(M16)の舞台。情景・命名の正は本節、マップ構成・接続・
経済の骨子は`game-design.md`「第2エリア(拡張: M16)」。

忘れ野の西、霧の溜まる低地の縁にある小さな集落。灯町が「まだ残る灯」に
寄り添う街なら、琥珀郷は「消えたあとの灯」で生きてきた土地である。消えた灯は
地中で凝り、琥珀――**灯の亡骸(ひのなきがら)**――となる。郷の民はかつて
それを坑から採り、磨いて暮らした。坑が封じられてからは人も減り、今は数軒の
家が囲炉裏の火を分け合うばかりの寂れた郷である。**安全地帯**(エンカウントなし)。

| 施設 | 情景 |
|---|---|
| 寄り屋(よりや) | 世話役イルマの住まいを兼ねた寄り合い所。大きな囲炉裏、煤けた梁、壁際に並ぶ空の寝台。宿相当(宿泊=セーブ・夢シーン) |
| 琥珀工房(こはくこうぼう) | 職人ガロの仕事場兼店。研ぎ台の上の灯の亡骸が燭台の火を受けて鈍く光る。棚には旅の道具と薬、それに売り物の細工が少し |
| 坑口(こうぐち) | 郷はずれの、板と鎖で封じられた採掘坑の入り口。番人トワがいつも縁に腰掛けている。第2ダンジョン「灯還りの坑」への入り口 |

### 2.5 第2フィールド — 「沈み野(しずみの)」(拡張: M16)

忘れ野の西縁から地続きに下る低地の荒野。霧が野の底へ沈み溜まり、昼でも
足元が白く煙る。忘れ野より綻びが濃く、裂け目の中でしか見ないはずの悪夢
(囁き仮面・軋み人形)が地表にまで滲み出している。枯れ草の間に灯の亡骸の
細片が混じって琥珀色に瞬く。採取ポイントが点在する(採れる物は忘れ野と同種)。
忘れ野と琥珀郷を結ぶ道でもある。

### 2.6 第2ダンジョン — 「灯還りの坑(ひがえりのこう)」(拡張: M16)

琥珀郷の民が灯の亡骸を採るために掘り進めた古い採掘坑。ある日、最奥で
「掘ってはいけないもの」に行き当たり、坑はそれきり封じられた。坑の名は、
消えた灯がここへ「還ってくる」という郷の言い伝えによる。

| 区画 | 空気感 |
|---|---|
| 坑道 | 木組みの支保が続く狭い坑道。壁に灯の亡骸の細片が埋まり、掲げる火に応えるように琥珀色に明滅する。放棄された燭台や手押し車が残る |
| 導管の間(最奥) | 坑夫たちが最後に掘り当てた、機関の一室。無数の**導管**が壁から闇の彼方へと伸び、そのほとんどは冷えて久しい。ただ幾本かは、今もかすかに温かい |

導管の間が示すのは、灯町も裂け目も機関の紡ぐ夢のごく一部に過ぎない、
という事実だけである(1.5「機関の全体像」の実体化)。導管がどこへ通じ、
その先で何が起きているのかは**本書では語らない**(具体的な地名も出さない。
メインクエスト第2章の領分として余地を残す)。最奥にボスは置かない。

## 3. 登場人物

### 3.0 共通ルール

- 一人称・語尾・口癖は会話プロンプトの人格描写にそのまま使ってよい
- 「秘密の深度」は好感度帯に対応させ、**帯は0-100の全域を覆う**:
  **30未満**=秘密には触れない(表面的・儀礼的な応対のみ)/**30-49**/**50-69**/
  **70以上**(各NPCの表を参照。初期値30。50以上で贈答解禁は`game-design.md`と
  共通の閾値)。DreamMasterは**該当帯の内容までしか匂わせてはならない**
  (上位の秘密を先出ししない)
- 台詞サンプルは世界観憲法(`ai-guardrails.md`)に従う例文であり、
  3文以内・日本語のみ・品位を保つことを常に満たす

### 3.1 主人公 — 名もなき旅人

記憶を失った旅人。年齢・性別・出自は不定(プレイヤーの分身として
過度に固定しない)。目覚めた時には、名も、故郷も、なぜここにいるのかも
覚えていなかった。持ち物は着の身着のまま、そして理由のわからない
小さな安堵だけがある。

- **記憶喪失の含み**: 単なる設定上の都合ではなく、1.5節の伏線そのもの。
  旅人が機関の夢に「属さない」存在であることの表れとして、他のNPCが
  時折、旅人の輪郭を掴みかねるような反応を見せてよい(怖れではなく、
  戸惑いや懐かしさに近い違和感として描くこと)
- **画像生成の要点**: 性別を強く特定しない中性的なシルエット、
  くすんだ旅装(青灰のマント、擦れた革の鞄)、輪郭の一部が霧に溶けるような
  淡い描写(「継ぎ目」であることを視覚的に匂わせる。ただし過度に
  異形化はしない)

### 3.2 宿屋の主人 — オルガ

| 項目 | 内容 |
|---|---|
| 役割 | 宿屋「灯宿」の主人。宿泊(セーブ・夢シーン)の窓口 |
| 外見 | 恰幅のよい初老の女性。灰の混じった三つ編み、火傷の跡が残る太い手、いつも羊毛の肩掛け |

## 6. 語りのトーンガイド

情景描写・NPC台詞・ナレーションいずれも「暗く、物哀しく、しかしどこか優しい」を
基準とする(`ai-guardrails.md`世界観憲法と同一基準)。以下は文体見本。

### 良い例

- 情景: 「霧が石畳を舐めるように這い、遠くの鐘が一度だけ鳴った。誰かを呼ぶような、
  それでいて誰も来ないとわかっている音だった」
- NPC台詞(オルガ): 「今夜はよく眠りな。悪い夢を見たって、朝には湯を沸かしておくからさ」
- ナレーション(戦果描写): 「刃が届くと、霧狼は声もなく崩れ、風に混じって消えた。
  何かを悼む間もないほど、静かな終わりだった」

### 避けるべき例

- 過度な残虐描写: 「返り血が飛び散り、断末魔の絶叫が響き渡った」
  (ゴア表現。`ai-guardrails.md`「語りの掟」に抵触)
- メタ的な言い回し: 「これはゲームのイベントです」「AIが生成した夢です」
  (世界の外側への言及。世界観憲法違反)
- 安易な断定・説明過多: 「実は司祭こそがすべての黒幕だったのだ」
  (本書が意図的に避けている構造。物語の余韻を壊す)

## 7. 実装・仕様との接続(参考)

- **宿泊=夢シーン**: 1.3節の因果をそのまま夢シーンのnarrateトーンに反映する
  (「今日の行いが夢に織り込まれる」ことを匂わせる一文を混ぜるとよい)
- **好感度と秘密**: 3.0節の帯(30/50/70)をNPC人物設定のプロンプト化時の
  基準として使う(`ai-integration.md`の`<npc_state>`)
- **噂・天候・street_event**: 各NPCの「夢との関わり」欄を参照し、
  誰にどの話題が乗りやすいかの手がかりとする
- **サブクエスト**: カイ(情報屋)を経由する想定に統一する
  (`game-design.md`のNPC表と一致)
- **全滅演出**: 1.3節後段の「代償」の描写を、全滅時のnarrateやUI文言に反映してよい
